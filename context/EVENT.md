# The event: The Agentic Room, 22 Nov 2026 (Paytm office, Bengaluru)

Run by KNOTiC, with Paytm as ecosystem partner. Judges: Akash Deb (co-founder, ElatoAI) and Arkaprava Ghosh (SDE-3, Adobe). Their talks were "Teardown: Anatomy of a Real Agent" and "Break the Agent".

## Brief
Build an agent that takes a real task from start to finish using at least one tool, then defend it against bad input.
We picked **Track 02, Commerce & payments**: agents that help a shopper or merchant decide or act, e.g. compare, reconcile, explain a bill, flag a risky transaction.

## Rules that constrain us
- **Fresh build:** a new repo, with the first commit after 12:10 on the day. Libraries and boilerplate are fine; finished projects are not.
  - Write all code here.
  - Don't copy code or data files from What They Meant.
- **No real money, no real data.** Mock or public data only. Never paste keys or personal data into a demo.
- **Any stack, any model.** Show at least one real tool call.
- **Public GitHub repo:** judges open it, so the README matters.

## Judging (100 pts)
| Pts | Criterion | What they look for |
|---|---|---|
| 30 | Real-world usefulness | Would someone actually use this tomorrow? Is the problem real and specific? |
| 25 | Agent design | Sensible tools, planning and memory. It acts; it doesn't just chat. |
| 25 | Unbreakable | Handles bad input, prompt injection and tool failure without falling over. |
| 20 | Demo & clarity | Works live, explained simply, within the time. |

## Submission
- **Repo:** a public GitHub repo with the code and a README.
- **Demo clip:** a **10-second** clip on Drive, YouTube or Loom, set to "anyone with the link". The top 5 are played on the big screen.
- **Form:** team name, project name, members, contact email and phone, repo link, clip link.

## Prizes and side games
- **Prizes:** Top 3 on the rubric, plus **Most Unbreakable Agent** (highest Unbreakable score).
- **Break-a-thon:** other teams try to break your agent, and each verified break scores a point for them. Expect real attacks.
