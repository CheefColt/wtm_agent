  - **Package `paycheck/`:**
    - `store.py`: loads data. `Session` is a per-chat copy of a persona, with cards, `blocked_handles`, `confirmed` and `fail_tools` (tests only).
    - `amounts.py`: `parse_amount` (15k, 1.5 lakh, words, Indian commas; refuses anything unclear, negative, zero or above ₹1 crore).
    - `text.py`: folds lookalike Cyrillic/Greek letters, normalises phone numbers, edit distance.
    - `safety.py`: the payment gate.
      - `create_card` checks the payee is in the directory, the amount is parsed, the per-payment cap is ₹50k, the daily cap is ₹50k counting all of today's payments, the balance covers it, and the payee is not blocked. A new card voids older open ones.

    - `tools.py`: 10 tools that return facts only, each with `ids` for highlighting. They are `search_contacts`, `payment_history`, `resolve_upi`, `get_balance`, `lookup_bills` (bills, subscriptions, offers), `get_orders`, `incoming_payments`, `read_message`, `decode_qr` and `propose_payment`.
      - `propose_payment` returns `_ui_token`, which the agent layer must strip before the model sees the result.
      - `call_tool` never raises.
  - All traps were smoke-checked by hand: each tool surfaces the deciding fact.
